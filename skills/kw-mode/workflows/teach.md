# Teach

Read [how](how.md) for mechanism and [why](why.md) for rationale as the question
requires. Start at the user's apparent knowledge and explain the smallest complete
idea first. Ground it in the actual behavior and one concrete example.

Connect the concepts in causal order. A list of functions is not an explanation.
Use a diagram when relationships are easier to see than describe. Preserve the
uncertainty of the investigation. Follow the user's questions into deeper layers;
do not turn a teaching request into a code change.
