# Blast radius

Read the changed contract and follow consumers beyond symbol references: persisted
data, wire formats, caches, background work, framework lifecycle, other languages,
feature flags, and external clients. Inspect the installed dependency version when
the safety claim relies on library behavior.

Find the one or two facts that make the change safe. Turn those into executable
probes against real code, then exercise the running surface when it matters. A list
of callers is not proof of compatibility. Use [prove it works](../principles/prove-it-works.md).

Return confirmed risks, risks checked and cleared, and assumptions still unproven.
Name the consequence and a realistic trigger. Do not inflate a review with generic
possibilities that the change cannot cause.
