# Recall

Fix the topic, project, and time range before searching. Start with context already
provided, then inspect in-scope handoff notes, working state, branches, and relevant
history. Use the current runtime's accessible session records only for this scope;
do not crawl private conversations across unrelated projects.

Reconcile remembered claims with current files and review status. Return the goal,
decisions, current artifact, verified progress, blockers, and next useful step.
Identify contradictions and missing evidence. For one specific session handoff,
use [session pickup](../playbooks/session-pickup.md).
