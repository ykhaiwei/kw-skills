# Why

Anchor the question in current files and symbols, then use blame, history, and
relevant review discussions to recover the decision. Search in-scope issues,
design documents, or connected services only when they can answer a remaining gap.
An installed connector is not a reason to search unrelated records.

Distinguish documented intent, a supported inference, and an unknown. Current code
proves current behavior; it does not prove the author's motivation. If a later
change invalidated the original reason, show that timeline.

Return the decision, evidence, tradeoff, and whether its constraints still hold.
Keep uncertainty in the explanation. Do not turn a plausible story into a fact.
