# Session pickup

1. Read the provided handoff and relevant in-scope history. Identify the original
   goal, accepted decisions, constraints, branch/worktree, and unfinished work.
2. Inspect live files, working state, processes, and review status. Reconcile the
   handoff against reality; do not assume its last reported head is still current.
3. Check whether recorded evidence applies to the present artifact. Re-run only
   checks invalidated by change, missing evidence, or an unresolved concern.
4. State the current outcome and next useful step briefly, then resume the matching
   playbook. Ask only for a decision or authorization that cannot be recovered.
5. Keep the original scope and user corrections through resumption. Do not redo
   completed work merely because this is a new session.
