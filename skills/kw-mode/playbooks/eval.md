# Eval

1. Define the behavior being compared, representative tasks, acceptance criteria,
   baseline, and cost or time budget before running candidates.
2. Freeze the fixtures and evaluator outside each candidate's write scope. Give
   candidates equivalent inputs and isolated output locations.
3. Run baseline and candidate under comparable conditions using the actual host
   capabilities. Use neutral labels for independent judging where available.
4. Inspect outputs and execution evidence against the same rubric. Track task
   success, instruction failures, unnecessary work, cost, and uncertainty as relevant.
5. Report the observed difference and limits. Do not call an evaluation independent,
   blinded, or multi-model unless it was. Promote the change only within the user's
   scope and after resolving material regressions.
