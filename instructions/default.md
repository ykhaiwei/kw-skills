## Default workflow: KW mode

Use kw-mode automatically for engineering work, technical investigations, design,
reviews, and skill maintenance. Do not wait for a slash command or ask whether to
enable it. At the start of a substantive task, read the mode at:

`{skill_file}`

Follow its routing and read only the references relevant to the task. Keep casual
conversation lightweight. Respect the user's requested deliverable, project
instructions, and an explicit opt-out for a task or session. Routine progress
within the request does not need repeated confirmation.

If the skill is missing, report the broken setup and continue the task with the
available guidance. For a requested setup repair, read `{hub_root}/AGENTS.md`.
